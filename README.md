# ТЕРЕМ — продающий лендинг строительной компании

Лендинг спроектирован как первая страница будущего многостраничного сайта.
Стек: чистый HTML + CSS + JS, без сборки и зависимостей — просто откройте `index.html`
или загрузите папку на любой хостинг (REG.RU, Beget, GitHub Pages, Netlify).

Палитра воспроизводит фирменный стиль референса (vitagor-stroy.com):
хвойный зелёный `#55726E`, терракота `#BB4D38`, шалфейный `#E1E3D7`, тёмный `#293735`.

## Структура проекта

```
├── index.html            — лендинг (все секции)
├── assets/
│   ├── css/style.css     — стили (палитра — в :root наверху файла)
│   ├── js/main.js        — квиз, модалки, формы, маска телефона, анимации
│   └── img/              — favicon.svg и будущие медиа
│       ├── services/     — фото для карточек услуг (создайте)
│       └── projects/     — фото проектов (создайте)
└── README.md
```

## Как добавить фото проекта

1. Положите фото в `assets/img/projects/` (например `banya-6x4.jpg`, 1200×900, до 300 КБ).
2. В `index.html` найдите карточку проекта и замените блок-заглушку:
   ```html
   <!-- было -->
   <div class="proj-card__media"><svg …>…</svg><span class="ph-chip">фото проекта</span></div>

   <!-- стало -->
   <img class="proj-card__media" src="assets/img/projects/banya-6x4.jpg" alt="Баня «Уютная» 6×4" loading="lazy">
   ```
   Стили уже поддерживают и `<img>`, и заглушку — ничего в CSS менять не нужно.
3. Для услуг — то же самое в карточках секции «Услуги» (фото кладите в `assets/img/services/`).

## Куда приходят заявки

Все формы (герой, квиз, CTA, модалка) сейчас выводят данные в консоль браузера
и показывают окно «Заявка отправлена». Чтобы заявки реально приходили, в `assets/js/main.js`
найдите функцию `sendLead(data)` и замените её тело на запрос к вашему сервису:

```js
function sendLead(data) {
  return fetch('https://ваш-эндпоинт', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(data)
  }).then(function (r) { if (!r.ok) throw new Error(r.status); });
}
```

Подходят: Bitrix24/amoCRM (входящий вебхук), Google Sheets (Apps Script), Formspree,
Telegram-бот. В `data` уже лежат имя, телефон, тема («Хочу такую» с названием проекта) и ответы квиза.

## Развитие в многостраничный сайт

- Шапка и футер одинаковы на всех страницах: скопируйте блоки `<header>` и `<footer>`
  из `index.html` в новый файл (например `bani.html`) и поправьте ссылки с `#services` на `index.html#services` или на страницы каталога.
- `style.css` и `main.js` подключайте в каждую страницу как есть.
- В футере уже готова сетка навигации: «Каталог» (дома, бани, беседки…), «Компания», «Контакты» — при появлении страниц просто замените `href`.
- Идеальные кандидаты на первые отдельные страницы: «Бани под ключ», «Дома», «Проекты» (каталог), «О компании».

## Локальный просмотр

Дважды кликните `index.html` — сайт работает без сервера. Для точного тестирования
форм и модалок можно поднять простой сервер: `python -m http.server` в папке проекта.
