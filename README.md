# Династия Дерева — продающий лендинг строительной компании

Лендинг спроектирован как первая страница будущего многостраничного сайта.
Стек: чистый HTML + CSS + JS, без сборки и зависимостей — просто откройте `index.html`
или загрузите папку на любой хостинг (REG.RU, Beget, GitHub Pages, Netlify).

Палитра воспроизводит фирменный стиль референса (vitagor-stroy.com):
хвойный зелёный `#55726E`, терракота `#BB4D38`, шалфейный `#E1E3D7`, тёмный `#293735`.

## Структура проекта

```
├── index.html            — лендинг (все секции)
├── assets/
│   ├── css/style.css     — стили (палитра — в :root наверху файла)
│   ├── js/main.js        — квиз, модалки, формы, маска телефона, анимации
│   └── img/              — favicon.svg и будущие медиа
│       ├── services/     — фото для карточек услуг (создайте)
│       └── projects/     — фото проектов (создайте)
└── README.md
```

## Как добавить фото проекта

1. Положите фото в `assets/img/projects/` (например `banya-6x4.jpg`, 1200×900, до 300 КБ).
2. В `index.html` найдите карточку проекта и замените блок-заглушку:
   ```html
   <!-- было -->
   <div class="proj-card__media"><svg …>…</svg><span class="ph-chip">фото проекта</span></div>

   <!-- стало -->
   <img class="proj-card__media" src="assets/img/projects/banya-6x4.jpg" alt="Баня «Уютная» 6×4" loading="lazy">
   ```
   Стили уже поддерживают и `<img>`, и заглушку — ничего в CSS менять не нужно.
3. Для услуг — то же самое в карточках секции «Услуги» (фото кладите в `assets/img/services/`).

## Куда приходят заявки

Все формы (герой, квиз, CTA, модалка) сейчас выводят данные в консоль браузера
и показывают окно «Заявка отправлена». Чтобы заявки реально приходили, в `assets/js/main.js`
найдите функцию `sendLead(data)` и замените её тело на запрос к вашему сервису:

```js
function sendLead(data) {
  return fetch('https://ваш-эндпоинт', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(data)
  }).then(function (r) { if (!r.ok) throw new Error(r.status); });
}
```

Подходят: Bitrix24/amoCRM (входящий вебхук), Google Sheets (Apps Script), Formspree,
Telegram-бот. В `data` уже лежат имя, телефон, тема («Хочу такую» с названием проекта) и ответы квиза.

## SEO: что уже есть и что сделать при деплое

Уже сделано (главная и страницы проектов/технологий):
- уникальные `title`/`description`, `canonical`, Open Graph + `og-cover.jpg` (1200×630);
- JSON-LD: `LocalBusiness` (организация, адрес, часы) и `FAQPage` (7 вопросов — шанс на расширенный сниппет в Яндексе и Google);
- `sitemap.xml` (12 URL) + `robots.txt`, `apple-touch-icon`, `theme-color`.

При покупке домена:
1. Замените `https://teren-stroy.ru` на реальный домен: в `index.html` (canonical, og:url, JSON-LD), и пересоберите проекты: `node tools/build-projects.mjs https://ваш-домен`.
2. Зарегистрируйте сайт в [Яндекс.Вебмастере](https://webmaster.yandex.ru) и [Google Search Console](https://search.google.com/search-console) — коды верификации вставьте в `index.html` в закомментированный блок `yandex-verification` / `google-site-verification`, затем добавьте sitemap в оба сервиса.
3. Поставьте счётчики: Яндекс.Метрика и GA4 — коды перед `</body>` в `index.html` (место помечено комментарием).

## Как добавить новый проект в каталог

Проекты хранятся в `assets/js/projects-data.js` (массив `TEREM_PROJECTS`).
Каталог `projects.html` рендерится из него в браузере, а SEO-страницы проектов
генерируются сборкой **в статику** — по файлу `/projects/<id>.html` на проект.

1. Положите PDF-листы проекта в папку внутри `Планы/<Имя проекта>/`.
2. Картинки — в `assets/img/projects/<id>/` (обложка `cover.webp` 1200×900, галерея до 1500px по большей стороне, WebP).
3. Добавьте объект проекта в `projects-data.js` (скопируйте беседку и замените поля).
4. Пересоберите статические страницы:

   ```bash
   node tools/build-projects.mjs                    # локально (база http://localhost:3000)
   node tools/build-projects.mjs https://ваш-домен  # при деплое — для canonical/sitemap
   ```

   Скрипт создаст `projects/<id>.html` (уникальные title/description,
   canonical, Open Graph, JSON-LD), обновит `sitemap.xml` и `robots.txt`.
5. На главную карточку добавьте руками по образцу «Беседка-павильон 14×12».

Старые ссылки вида `project.html?id=...` работают — `project.html` редиректит
на статическую страницу. При смене домена перегенерируйте сборку с новым URL.

Генерация картинок из PDF (нужен `pip install pymupdf`):

```python
import pymupdf
doc = pymupdf.open(r'Планы/<проект>/<файл>.pdf')
doc[25].get_pixmap(matrix=pymupdf.Matrix(2.2, 2.2)).save('viz.png')  # лист 26 → PNG
```

Важно: титульный лист и пояснительная записка содержат имена заказчика/архитектора —
если проект чужой, удалите их из `docs` перед публикацией.

## Развитие в многостраничный сайт

- Шапка и футер одинаковы на всех страницах: скопируйте блоки `<header>` и `<footer>`
  из `index.html` в новый файл (например `bani.html`) и поправьте ссылки с `#services` на `index.html#services` или на страницы каталога.
- `style.css` и `main.js` подключайте в каждую страницу как есть.
- В футере уже готова сетка навигации: «Каталог» (дома, бани, беседки…), «Компания», «Контакты» — при появлении страниц просто замените `href`.
- Идеальные кандидаты на первые отдельные страницы: «Бани под ключ», «Дома», «Проекты» (каталог), «О компании».

## Локальный просмотр

Дважды кликните `index.html` — сайт работает без сервера. Для точного тестирования
форм и модалок можно поднять простой сервер: `python -m http.server` в папке проекта.
